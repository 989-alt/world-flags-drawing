# 세계 국기 따라 그리기 웹앱 설계

## 왜 만드는가

초등학교 6학년 중증 자폐 학생이 세계 여러 나라의 국기를 **종이에 따라 그리는** 수업에서 쓸 견본 화면이다.
학생은 크롬북이나 태블릿에서 국기를 골라 크게 띄워 놓고, 그것을 보며 종이에 그린다.
그리는 동안 그 나라의 이름, 수도, 위치, 인사말, 문화를 사진과 쉬운 글로 함께 배운다.

학생은 나라 이름 같은 **단어는 읽지만 문장은 어려워한다.** 그래도 선생님은 낱말만 늘어놓으면 배우는 게 없다고 보신다.
그래서 문화는 실제 사진과 이해하기 쉬운 한 단락으로 소개하고, 선생님이 옆에서 읽어 주며 함께 본다.

## 목표

- 대륙별로 나라를 골라 국기를 **크고 정확하게** 보여 준다.
- 국기를 **색 보기**와 **테두리만 보기**(색이 빠진 밑그림)로 바꿔 볼 수 있다.
- 국기 아래에 나라 소개를 보여 준다.
  - 나라 이름
  - 수도
  - 세계 지도에서 위치
  - 인사말: 현지 글자와 한글 발음. 예: こんにちは (곤니치와)
  - 문화 3가지: 실제 사진, 제목, 이해하기 쉬운 한 단락
- 링크 하나로 크롬북과 태블릿에서 바로 연다(GitHub Pages).

## 하지 않는 것

- 화면에 직접 그리는 기능, 인쇄 기능
- 그린 국기 기록, 진행 표시, 로그인
- 소리(읽어 주기 포함), 퀴즈
- 국기 화면에서 이전/다음 나라로 넘어가기. 목록으로 돌아가는 버튼만 둔다.
- 한국어 말고 다른 언어 지원

## 실패로 여기는 것

- **움직이는 효과**: 반짝임, 튀는 애니메이션, 자동 전환, 화면 전환 효과
- **갑작스러운 소리**: 어떤 소리도 내지 않는다.
- **복잡한 화면**: 한 화면에 요소가 많은 것, 작은 글씨, 좁은 여백
- **틀린 국기**: 비율, 색, 별 개수, 문양이 틀린 국기. 따라 그리는 견본이므로 가장 중요하다.
- **틀리거나 고정관념에 기댄 문화 설명**
- **출처와 라이선스가 불분명한 사진**

### 국기 화면

- 국기 화면을 열 때마다 "색 보기"로 시작한다.

## 내용

### 나라 수와 고르는 기준

약 80개 나라를 넣는다. 대륙별 대략 배분은 다음과 같다.

| 대륙 | 나라 수 |
|---|---|
| 아시아 | 20 |
| 유럽 | 25 |
| 아프리카 | 12 |
| 북아메리카 | 8 |
| 남아메리카 | 8 |
| 오세아니아 | 4 |

고르는 기준은 "중학생이 들어 봤을 만한 나라"다.

- 북아메리카에는 중앙아메리카와 카리브해를 포함한다(예: 멕시코, 쿠바).
- 러시아와 튀르키예는 **유럽**에 둔다. *(제 판단)*
- 이집트는 **아프리카**에 둔다. *(제 판단)*

### 국기

- 열린 라이선스의 SVG를 쓰고, 나라마다 원래 비율을 지킨다(예: 스위스 1:1, 네팔은 사각형이 아님).
- 정확성이 가장 중요하므로 출처가 분명한 공개 자료에서 가져와 저장소에 넣는다.
- 테두리만 보기:
  - 같은 SVG에서 색을 흰색으로 바꾸고 모든 도형에 검은 선을 그린다.
  - 문장(紋章)처럼 복잡한 그림이 있는 국기는 선이 많아 보여도 그대로 둔다. *(제 판단)*

### 지도

세계 지도에서 그 나라를 강조색으로 칠하고, 나머지는 옅은 회색으로 둔다.
아주 작은 나라(싱가포르, 바티칸 등)는 지도에서 안 보이므로 위치에 동그라미 표시를 함께 그린다. *(제 판단)*

### 인사말

- 현지 글자와 한글 발음을 함께 적는다. 예: Bonjour (봉주르)
- 그 나라에서 가장 널리 쓰는 말 하나만 적는다.

### 문화 3가지

- 나라마다 서로 다른 갈래에서 3가지를 고른다. 예: 음식, 옷이나 축제, 유명한 장소나 동물
- 각 항목은 사진 1장, 제목(낱말), 한 단락으로 구성한다.
- 한 단락은 3~4문장이다.
  - 초등 저학년이 들어도 알 쉬운 낱말을 쓰고, 문장은 짧게 쓴다.
  - "~이에요/~해요" 말투로 쓴다.
  - 예: "김치는 배추에 고춧가루, 마늘을 넣어 버무린 한국의 반찬이에요. 맵고 새콤한 맛이 나요. 겨울이 오기 전에 가족과 이웃이 모여 함께 김치를 담가요. 이것을 김장이라고 해요."
- 사진:
  - 위키미디어 공용(Wikimedia Commons)에서 고른다.
  - 라이선스는 퍼블릭 도메인, CC0, CC BY, CC BY-SA만 쓴다.
  - 사진 아래에 작은 글씨로 작가와 라이선스를 적는다.
  - 화면용으로 줄인 사본(가로 800px 안팎)을 저장소에 넣는다.

### 내용 정확성과 검토 (선생님 결정)

- **Claude가 점검한다.** 선생님은 수업하면서 눈에 띄는 것만 고친다.
  - 국기: 가져온 SVG를 두 번째 공개 자료(위키백과 국기 문서 등)와 대조한다. 비율, 색, 문양 수(별 개수 등)를 확인한다.
  - 수도·인사말·문화 글: 두 번째 자료로 사실을 확인한다. 고정관념에 기대는 표현은 쓰지 않는다.
  - 사진: 위키미디어 공용 파일 페이지에서 라이선스와 작가를 확인해 데이터에 적는다.
- **나중에 고칠 때는 Claude에게 부탁한다.** 선생님이 직접 파일을 고치지 않는다. 데이터 형식은 만드는 사람에게 맡긴다.
  - 그래도 나라 정보는 한 데이터 파일에 모아서, 고칠 때 한 곳만 바꾸면 되게 한다.
- 수도는 일반적으로 가르치는 곳으로 적는다(예: 오스트레일리아는 캔버라, 튀르키예는 앙카라).

### 민감한 나라와 지도 (선생님 결정)

- 논란이 있는 나라는 **넣지 않는다**: 대만, 북한, 팔레스타인, 코소보.
- 지도는 나라 위치만 칠하고 **글자를 넣지 않는다**(바다 이름, 섬 이름, 나라 이름 없음).
- 독도는 대한민국으로 칠한다.
- 분쟁 국경은 특별히 표시하지 않는다.

### 일정 (선생님 결정)

약 80개 나라를 **한 번에 모두** 완성한 뒤 쓰기 시작한다.

## 화면 원칙

- 애니메이션, 전환 효과, 소리를 쓰지 않는다. 화면은 누를 때만 바뀐다.
- 누르는 곳은 최소 56px 높이로 하고, 글씨는 본문 20px 이상, 나라 이름은 그보다 훨씬 크게 쓴다.
- 차분한 색에 넓은 여백을 둔다. 강조색은 하나만 쓴다.
- 크롬북(가로 화면)과 태블릿(가로·세로)에서 가로 스크롤 없이 보여야 한다.
- 한국어 웹 글꼴을 쓰되, 글꼴을 불러오지 못해도 시스템 글꼴로 읽을 수 있어야 한다.

## 만드는 방법 (제 판단)

- 빌드 단계 없는 정적 사이트(HTML, CSS, JavaScript)로 만든다.
  - GitHub Pages에 그대로 올라가고, 선생님이 데이터 파일만 고쳐도 반영된다.
- 국기, 지도, 사진은 모두 저장소에 넣는다. 수업 중에 외부 사이트가 막혀도 화면이 깨지지 않게 하기 위해서다.
- 데이터 파일 검사를 자동 테스트로 만든다.
  - 모든 나라에 필수 항목이 있는지
  - 국기, 사진 파일이 실제로 있는지
  - 사진마다 출처가 있는지
- 화면 동작(대륙 전환, 국기 열기, 테두리 전환, 돌아가기)은 브라우저 자동 테스트로 확인한다.
- 저장소에 아직 기본 브랜치가 없다. 첫 결과물이 기본 브랜치가 되면 선생님이 저장소 설정에서 GitHub Pages를 켜야 한다(안내 제공).

## 만드는 사람에게 맡기는 것

- 파일 구조, 코드 구조
- 국기 SVG와 지도 데이터를 어느 공개 자료에서 가져올지(위 조건을 지키는 한)
- 나라별 문화 3가지와 사진 고르기
  - 위 기준을 지킨다.
  - 선생님이 나중에 데이터 파일에서 바꿀 수 있다.
- 색과 글꼴의 세부값. 시안의 분위기를 따른다.
